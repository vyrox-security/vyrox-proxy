# Code of Conduct

## Professional Expectations

This repository contains security execution code that can isolate production hosts. Treat all interactions as professional engineering work.

## Expected Behavior

- Be precise and respectful
- Focus criticism on code and decisions, not people
- Provide reproducible evidence for claims
- Report mistakes quickly and clearly

## Unacceptable Behavior

- Harassment, abuse, or personal attacks
- Intentionally misleading security advice
- Posting secrets, tenant data, or sensitive operational details
- Spam or repeated low-effort noise in issues and PRs

## Enforcement

Maintainers may edit, lock, remove, or restrict participation for behavior that degrades project safety or review quality.
